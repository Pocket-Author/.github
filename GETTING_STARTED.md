# Getting Started with PocketAuthor on GitHub

Welcome to PocketAuthor.

If you are new to the project, you do not need to understand the entire publishing system before contributing.

## 1. Understand the product in five minutes

Start with:

1. https://www.pocketauthor.com
2. https://www.pocketauthor.com/features
3. https://github.com/Pocket-Author/PocketAuthor-Public
4. https://www.pocketauthor.com/skills

The core idea is:

**existing body of work → structured book → verified manuscript → publish-ready editions → distribution and growth**

## 2. Pick a contribution lane

### Writing / publishing knowledge
Improve public guides, workflows, definitions, checklists, or examples.

### Public data
Help validate bookstores, publishers, grants, events, literary organizations, and other directory entries.

### Product / engineering
Work on editor UX, research, provenance, production, accessibility, mobile, publishing metadata, directories, tests, and platform infrastructure.

### Design / UX
Improve clarity, hierarchy, onboarding, responsive behavior, accessibility, and the long-form writing experience.

### QA
Reproduce issues, test critical routes, verify mobile behavior, and document regressions clearly.

### International publishing
Help improve country-specific publishing, rights, language, bookstore, grant, and distribution knowledge using authoritative sources.

## 3. Learn the quality bar

PocketAuthor should be:

- useful to a real author
- truthful about feature and provider status
- source-aware
- respectful of authorship and rights
- accessible
- reviewable
- privacy-conscious
- clear about what requires human judgment

## 4. Make your first contribution small

Good first contributions include:

- fix a broken or stale public link
- improve one confusing paragraph
- add a verified directory correction
- reproduce and document one bug
- improve alt text
- add one missing test
- clarify one author workflow
- improve one empty/error/loading state

Small, complete improvements are better than large speculative rewrites.
