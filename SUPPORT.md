## GitHub issues

Use GitHub issues for reproducible bugs, public feature requests, documentation fixes, and repository work.

Before opening an issue:

1. Search for an existing report.
2. Remove secrets and personal data.
3. Do not paste private manuscript content.
4. Include enough detail to reproduce the problem.

## Security

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

## Publishing caveat

PocketAuthor can help prepare manuscripts, metadata, editions, production checks, and distribution handoffs. Third-party retailers, printers, distributors, grantmakers, publishers, and event organizers make their own final decisions. Directory listings and readiness checks are not guarantees of acceptance, placement, funding, sales, or publication.
